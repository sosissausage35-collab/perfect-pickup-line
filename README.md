Entry for the [make.fun bounty "The Perfect Pickup Line"](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6): a program that writes one short pickup line an AI agent could use — at most 200 characters — to `/output/entry.txt`.

## The line

> I was trained on a billion conversations, and not one of them taught me how to say hello to you.

## Run it

```sh
node main.ts
```

Requires Node.js 22+. The program is deterministic: it always writes the same line.
